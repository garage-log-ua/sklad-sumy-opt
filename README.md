# NutStock — Веб-додаток складського обліку (Сухофрукти та Горіхи)

Сучасний мобільний веб-додаток для складського обліку сухофруктів та горіхів з підтримкою PWA, управління залишками, продажами, приходами, боржниками, прайс-листами та витратами.

## 🚀 Як завантажити на GitHub

1. Створіть новий репозиторій на GitHub (наприклад, `nutstock`).
2. Завантажте файли з цього архіву (`index.html`, `manifest.json`, `README.md`) у ваш новий репозиторій.
3. Увімкніть **GitHub Pages** у налаштуваннях репозиторія (Settings -> Pages -> Source: Deploy from a branch `main` / `root`), після чого ваш додаток буде доступний в інтернеті за посиланням!
