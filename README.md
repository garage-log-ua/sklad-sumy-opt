# NutStock — Веб-додаток складського обліку (Сухофрукти та Горіхи)

Сучасний мобільний веб-додаток для складського обліку сухофруктів та горіхів з підтримкою PWA (встановлення на головний екран смартфону), управління залишками, продажами, приходами, боржниками, прайс-листами та витратами.

## 🚀 Як завантажити на GitHub

1. Створіть новий репозиторій на GitHub (наприклад, `nutstock`).
2. Завантажте файли з цього архіву (`index.html`, `manifest.json`, `README.md`) у ваш новий репозиторій.
3. Увімкніть **GitHub Pages** у налаштуваннях репозиторія (Settings -> Pages -> Source: Deploy from a branch `main` / `root`), після чого ваш додаток буде доступний в інтернеті за посиланням!

## 📱 Функціонал
- **Перший запуск:** Налаштування назви компанії/ФОП та вибір початкових даних (чистий склад або демо).
- **Склад:** Облік залишків у кг та ящиках, загальна вартість закупівлі.
- **Продаж:** Оформлення замовлень, редагування цін в реальному часі, продаж «в борг».
- **Прихід:** Оприбуткування товару з автоматичним перерахунком собівартості.
- **Боржники:** Облік дебіторської заборгованості з чеками закриття видаткових накладних.
- **Прайс-лист:** Генерація та попередній перегляд актуальних цін.
- **Витрати:** Облік поточних витрат з фільтрами періодів та календарем.
- **PWA:** Працює як нативний додаток на iOS та Android.
